# Rust'R Us
Free browser-native industrial space salvage game. v0.2 is a generated-art flight test, not the finished game. Run npm install then npm run dev; npm run build checks TypeScript and builds dist. The original 2D prototype is in legacy/. Controls shown in game. Flight to the field takes roughly 80 seconds at maximum speed; longer voyages, true orbital docking, EVA, sound and Kenney assets are future milestones. All geometry is generated in code. GitHub Pages deployment requires Settings > Pages > GitHub Actions. No paid services required for this public repository within GitHub's limits.
